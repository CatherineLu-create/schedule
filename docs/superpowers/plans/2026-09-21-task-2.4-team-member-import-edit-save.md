# Task 2.4 Team Member Import, Edit, and Save Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Complete one slice, obtain independent review, commit only its scoped files, and STOP for human approval before starting another slice.

**Goal:** A Project's Team Member resource can import CSV/XLS/XLSX, edit a complete roster, and atomically Save to its current-session `Project.team` without losing source columns or changing any other Project.

**Architecture:** `PrototypeState.projects[ProjectId].team` remains the sole saved Team authority. A local editor holds an isolated candidate; parsing creates a separate import candidate. Pure domain mapping and validation turn a resolved candidate into a `ProjectTeam`; `saveProjectTeam` returns one Project replacement, and App dispatches one existing `projectReplaced` action. The UI reads normal assignments and preserved unclassified entries through one projection of that same aggregate. No second store, Provider, repository, service, backend, or Schedule-style Draft lifecycle.

**Tech Stack:** Existing React, TypeScript, Vite, Vitest, Testing Library, and installed `xlsx`. No dependency or configuration change is planned.

**Spec:** [2026-09-18-task-2.4-team-member-import-edit-save-design.md](../specs/2026-09-18-task-2.4-team-member-import-edit-save-design.md), checkpoint `cabc369a2e67531bd069d15afdb893eaa27ee92a`.
